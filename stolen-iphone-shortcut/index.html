Charger trap · reverse engineer

iPhone stolen. Thief plugs it in. Front camera + location fire.

When the phone connects to power, a Shortcuts automation can wake cellular, grab GPS, snap a selfie, and send it to you — a backup after Find My / Lost Mode / Stolen Device Protection.

iOS Shortcuts Trigger: Charger connected Tap checklist ↓

Do this first (real recovery)

The shortcut is a backup. Official tools come first.

Open Find My on iCloud Lost Mode help

  • Mark as Lost in Find My

    Locks the device, shows a custom message + phone number, tracks location when online.

  • Confirm Stolen Device Protection

    Settings → Face ID & Passcode → Stolen Device Protection — delays sensitive changes away from familiar locations.

  • Report to carrier + police

    IMEI blacklist / case number still matter even if the shortcut later pings.

Build the Shortcuts automation

Typical @Numan_Ai12-style flow. Tap each step as you configure it on your phone.

0 / 8

  • Open Shortcuts → Automation

    Create Personal Automation (not a shareable Shortcut alone — you need the Automation trigger).

  • Trigger: Charger → Is Connected

    When power connects (Lightning/USB-C/MagSafe), the automation starts.

  • Run Immediately (no Ask Before Running)

    Critical: disable confirmation so it can fire while the phone is in someone else’s hands.

  • Turn Airplane Mode off

    Action: Set Airplane Mode → Off (thief may have toggled it to kill Find My).

  • Enable Cellular Data

    Set Mobile Data / Cellular Data → On so email/iMessage can leave the device.

  • Get Current Location (high accuracy)

    Get Current Location → Current Location; prefer Precise Location allowed for Shortcuts.

  • Take Photo — Front, Show Preview OFF

    Camera → Front; turn off Show Camera Preview so it doesn’t flash a big UI to the thief.

  • Send Email (or Message) with location + photo

    Attach Current Location + the photo; recipient = your backup email or trusted contact. Test once yourself.

Caveats — it can fail

Encode these before you trust it.

  • Locked phone, missing permissions, Low Power Mode, or iOS version quirks can block camera / location / Mail actions.
  • Stolen Device Protection and Lockdown Mode may restrict automation or network behavior — test on your device/OS.
  • It also fires on your normal charging. Add a confirmation dialog, Focus filter, time window, or “Ask Before Running” if daily false positives annoy you (trade-off vs stealth).
  • Thief never plugs in → nothing sends. Find My + police report remain primary.
  • Privacy: you are building a self-surveillance trap on your own device — don’t deploy this pattern on someone else’s phone.

Iteration ideas

  • Time window — only run overnight / outside work hours so home charging is quiet.
  • Wi-Fi SSID check — skip if connected to “Home” / office; fire only on unknown networks.
  • Dual channel — email + iMessage (or Telegram via API shortcut) in case one fails.
  • Battery % — also trigger on Battery Level drops / rises past a threshold while locked.
  • Silent log — append to iCloud Drive note with timestamp even if send fails.
